# Omarchy macOS (dark)

Custom [Omarchy](https://github.com/basecamp/omarchy) desktop theme inspired by macOS dark mode.

Compatible with Omarchy theme install expectations: configs at repo root plus optional wallpapers under [`backgrounds/`](./backgrounds).

## Install

```sh
omarchy-theme-install https://github.com/ben-fornefeld/omarchy-macos-theme.git
```

This installs to `~/.config/omarchy/themes/macos` and activates the theme (see `omarchy-theme-install` in your Omarchy version).
